# Changelog

All notable changes to this project are listed here. The project follows [Semantic Versioning](https://semver.org).

## [Unreleased]

## [1.1.0] - 2026-10-16

### Added

- Install as a plugin in Claude Code and Codex, with marketplace files for both.
- `CONTRIBUTING.md` with how to report problems, request skills and submit changes.

### Changed

- README links to the privacy policy and terms of use.

## [1.0.0] - 2026-10-14

First release.

### Added

- `android-architecture` skill: project structure, layer boundaries, naming, visibility and dependency injection.
- `android-patterns` skill: unidirectional data flow, ViewModels, UI state, Flow composition, error handling, repositories, use cases and Compose UI.
- `android-testing` skill: JUnit 5, Turbine, MockK or Mockito-Kotlin, test naming and structure, parameterized tests.
- Setup guide for Gemini in Android Studio, Codex and Claude Code, with macOS, Linux and Windows commands.
- Plugin manifest, privacy policy and terms of use.
