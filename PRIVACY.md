# Privacy Policy

android-engineering-skills is a set of Markdown files that AI coding agents read as instructions.

The skills do not collect, store or send any data. They contain no code that runs on your machine, make no network requests and include no analytics or telemetry.

The AI coding agent you use with these skills has its own privacy policy. Check it to understand how your code and prompts are handled.

Questions about this policy can be raised as an issue on the [GitHub repository](https://github.com/lennonpetrick/android-engineering-skills/issues).
